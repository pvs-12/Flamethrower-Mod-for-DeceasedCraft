# Flamethrower Mod (for DeceasedCraft)

A custom Minecraft Forge mod designed to be compatible with both:
- **DeceasedCraft v5.5.5** (Latest Stable — **Minecraft 1.18.2**, Forge `40.2.4`)
- **DeceasedCraft Beta-5.10.17** (Latest Public v6 Open Beta — **Minecraft 1.20.1**, Forge `47.4.0`)

## Modpack Research & Compatibility Reference
- **[DeceasedCraft_Mod_Research.xlsx](docs/DeceasedCraft_Mod_Research.xlsx)** — Complete 3-sheet Excel workbook cataloging all 224 mods in `v5.5.5`, all 307 mods in `Beta-5.10.17` (including Distant Horizons edition), `MC 1.20.1 (Forge)` support status for every `v5.5.5` mod, unified 17-category taxonomy, and a dual-version mod-development compatibility guide.
- **[RESEARCH_SUMMARY.md](docs/RESEARCH_SUMMARY.md)** — Summary of modpack counts, category breakdown, unported `1.18.2` mods, and verification results.
- **[docs/scripts/](docs/scripts/)** — Reproducible Python scripts used to extract CurseForge manifests, verify `1.20.1` compatibility across CurseForge/Modrinth/GitHub, categorize all 380 unique mods, and build/verify the Excel workbook.
